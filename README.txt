RoutineWidget iPad PWA v1.0
============================

이 버전은 Swift Playgrounds가 필요 없습니다.
Safari에서 실행한 뒤 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

중요
----
PWA 설치와 오프라인 기능을 사용하려면 이 폴더를 HTTPS 웹 주소에 올려야 합니다.
파일 앱에서 index.html을 직접 여는 방식(file://)은 PWA 설치 방식이 아닙니다.

권장 배포: GitHub Pages
----------------------
1. GitHub에 새 저장소를 만듭니다.
2. 이 폴더 안의 파일을 저장소 최상위에 업로드합니다.
3. 저장소 Settings > Pages로 이동합니다.
4. Deploy from a branch를 선택하고 main / (root)를 지정합니다.
5. 생성된 https://...github.io/... 주소를 iPad Safari에서 엽니다.
6. Safari 공유 버튼 > 홈 화면에 추가를 선택합니다.
7. 홈 화면의 '반복 루틴' 아이콘으로 실행합니다.

사용법
------
- 현재 시간에 따라 완료 / 진행중 / 대기가 자동 변경됩니다.
- 현재 루틴은 파란 카드로 강조됩니다.
- 왼쪽 시간축에 현재 시각 포인터가 표시됩니다.
- 루틴 설명은 길어지면 카드 안에서 자동 줄바꿈됩니다.
- 상단 '동기화' 버튼을 누르면 routine.json 파일을 불러올 수 있습니다.
- 불러온 JSON은 브라우저에 저장되므로 앱을 다시 실행해도 유지됩니다.
- ... > 내장 샘플로 복원 으로 초기 상태로 돌아갈 수 있습니다.
- 서울 현재 날씨는 Open-Meteo를 사용하며 30분마다 갱신됩니다.

routine.json 형식
-----------------
요일 번호:
0 = 일요일
1 = 월요일
2 = 화요일
3 = 수요일
4 = 목요일
5 = 금요일
6 = 토요일

시간은 자정부터 지난 '분'입니다.
예: 10:00 = 600, 11:45 = 705

예:
{
  "version": 1,
  "days": {
    "4": [
      {
        "start": 600,
        "end": 705,
        "title": "책 모작 · 안보고 그리기",
        "tasks": ["작법서 예제 모작", "기억으로 다시 그리기", "원본과 비교"]
      }
    ]
  }
}

파일 구성
---------
index.html              메인 화면
styles.css              확정한 iPad 디자인
app.js                  시간/루틴/달력/날씨/JSON 기능
manifest.webmanifest    PWA 설정
sw.js                   오프라인 앱 셸 캐시
sample-routine.json     기본 샘플 루틴
icons/                  홈 화면 아이콘
